# Phase 1: decisions and gaps from the legacy migration

Generated by `scripts/build-data/migrate/cli.mjs`. Nothing was invented: each item is a place where the old CSV was ambiguous, where a value was derived from its wording, or where data is missing. Where the old data does not say, the cell is left empty (ac_powered, poe and uplink_mgig are set only when the old data states them; an absent value is never turned into "no"). Every migrated row starts as `draft`.

## All families

### Product names (1)

- name_tr and name_en are both the legacy product name or PID (names are not translated). summary_tr, good_for_tr and the series explainers are empty: they are Turkish text that needs writing and a native review.

### Management mode is derived (1)

- The legacy files have no management field. Switching and routing: Meraki -> cloud; Catalyst -> on_prem, plus cloud when "Unified Architecture" is Yes; Cisco Business -> cisco_business; ASR -> on_prem. Wireless: Unified -> on_prem + cloud; Catalyst and Catalyst IW -> on_prem; Meraki -> cloud; Cisco Business -> cisco_business + embedded. Data center: NX-OS -> nexus, MDS -> san, Hyperfabric -> hyperfabric. Confirm that "Unified" really means "can run either way" (SPEC "Management toggle").

### Datasheet links repaired and third-party hosts (1)

- Legacy links without https:// were repaired by adding the prefix (bare cisco.com/... became https://www.cisco.com/...). The links themselves are untested until the Phase 7 link check. A few datasheet links in the old data point away from cisco.com (for example meraki.cisco.com, data.nag.wiki on excluded ASR modules); check:data warns on any host that is not cisco.com or meraki.com.

### Nothing is recommended, nothing is "new" (1)

- recommended, recommended_why_tr and added_date are empty on every row: the SPEC wants one hand-picked recommendation per series, and the "Yeni" badge depends on a real added_date.

- 51 routers in the ASR and NCS product lines (ASR 900/920/9000, NCS 540/560/5500/5700) are scope=excluded: kept in the workbook, skipped by every check, never on the site.
